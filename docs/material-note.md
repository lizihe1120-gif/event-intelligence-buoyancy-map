## 结论先行

最终选择中国船舶（600150.SH）、中国重工（601989.SH，已于2025-09-05因吸收合并终止上市）和中国动力（600482.SH）。主事件是“中国船舶换股吸收合并中国重工”。材料共18个去重后的独立文档条目，覆盖市场传闻、公司公告、新闻、专家/研报观点、监管批复、连续停牌、换股实施、终止上市、历史行情和另一宗交易终止。

当前主事件的确认状态为**已确认**，执行状态为**已完成**，市场反应状态为**出现初步反应后回撤**。三者必须分开展示。

## 为什么选这三个公司

- 中国船舶是吸并方及存续上市公司。
- 中国重工是被吸并方，合并后终止上市并不再保留独立主体资格。
- 中国动力不是随意挑选的同行。中国重工合并前直接持有其股份，主合并直接触发其权益承继披露；中国船舶承继相关权益，但中国动力实际控制人不变。

这组关系允许产品同时展示“存续方—消失方—被穿透影响的第三方上市公司”。

## 为什么选这个主事件

候选比较包括“两船合并”“国泰君安吸并海通证券”以及若干A股重组/澄清事件。两船合并的优势是：

1. 有多年市场传闻和“南北船/中国神船”叙事；
2. 有2021年五年内解决同业竞争的正式承诺；
3. 有2024年停牌筹划、预案、换股比例和复牌；
4. 有新闻跟进、投顾采访和券商研报观点；
5. 有交易所审核、证监会注册、终止上市和换股实施；
6. 最终实施比例1:0.1339替代预案阶段的1:0.1335，形成清晰的版本更新；这不表示预案比例披露错误；
7. 市场表现与“交易已经落地”并不等价，适合演示确认、执行、市场反应彼此独立的状态模型。

- 中国重工：4.98元至4.86元，-2.41%；复牌日成交额21.70亿元，约为停牌前11.21亿元的1.94倍。9月20日收4.50元，单日-7.41%。
- 中国动力：预案披露日23.35元至次日22.09元，-5.40%；成交量约1.77倍。
- 上证综指9月18日至19日约+0.69%，9月19日至20日约+0.03%。

可用表述是“公告披露后观察到价格和成交显著变化，并在次日出现回撤”，不能表述为“公告导致下跌/上涨”。详细原始值、公式和限制见 `data/demo/market-reactions.json`。

## 交易状态与气泡展示

### 资产主体颜色

- 正常交易：使用正常资产气泡材质。
- 停牌：资产气泡主体变为灰色。
- 终止上市：使用更深的灰色、空心或逐渐消散的形态。
- 灰色只表示当前不可交易，不能表示利空、证据失效或来源不可信。

### 停牌价格展示

停牌时只显示“停牌中”“最后交易价”和“最后交易日”，不显示实时价格或一小时涨跌。

中国重工终止上市后应显示“已终止上市”“最后交易日”和换股去向或权益承继说明，不能继续显示为普通“停牌中”。

### 事件影响方向

- 利好事件使用红色，利空事件使用绿色。
- `mixed`允许在资产边缘同时出现红色和绿色局部光弧。
- `unclear`不强制转换成红色或绿色。
- 事件红绿不能覆盖资产停牌时的灰色主体；一个灰色停牌资产可以同时连接红色和绿色事件。

### 视觉状态分工

```text
资产主体颜色
= 交易状态

事件和连接的红绿
= 对公司的影响方向

证据小泡泡是否融入主事件
= 信息确认程度

事件泡泡是否接近或融入资产
= 市场反应或计价程度
```

页面不得合并以下概念：已确认不等于已实施；已实施不等于已计价；股价上涨不等于消息真实；停牌不等于利空；终止上市不等于普通停牌。
