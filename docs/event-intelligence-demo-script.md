# “事件浮力图”演示视频脚本

## 成片目标

- 实际成片时长：101.2 秒；符合 60–180 秒要求。
- 目标分辨率：1440×900。
- 目标文件：`outputs/event-intelligence-web/event-intelligence-demo.mp4`。
- 画面范围：只录制本地事件浮力图页面，不出现桌面、终端、环境变量、API Key、浏览器个人信息或无关项目。
- 声音方案：无音轨，使用画面内中文字幕。
- 事实边界：演示当前已经实现的三个快照、液态关系、事件详情、通知中心、七步分析过程和公网版本；不声称存在实时抓取、外部采集 Agent 或在线模型调用。

## 实际成片镜头

实际成片依次展示：产品开场、三家公司关系、筹划停牌快照、预案复牌快照、实施完成快照、五种关系形态、事件概览、版本演化、证据与冲突、AI 分析记录、七步分析过程、通知中心和投资声明。字幕直接嵌入画面，未出现桌面、账号信息、环境变量或 API Key。

## 录制前准备

在 `D:\AIcoding` 执行：

```powershell
npm run pipeline:generate --workspace @event-intelligence/web
npm run dev --workspace @event-intelligence/web -- --host 127.0.0.1 --port 5174
```

实际成片使用公网地址 `https://lizihe1120-gif.github.io/event-intelligence-buoyancy-map/`，录制视口为 1440×900。页面默认位于 `2025-09-16 · 实施完成`。

## 镜头表与旁白

### 00:00–00:10｜产品开场

**页面操作**

- 显示完整首屏。
- 镜头保持稳定，标题“事件浮力图”和副标题“中国船舶集团重大重组”可读。

**旁白/字幕**

> 事件浮力图，帮助投资者看清同一事件的最初来源、事实变化、当前状态，以及受影响标的之间的关系。

**画面检查**

- 不放大到裁掉三家公司或图例。
- 右上角能看到“DEMO / 演示快照”。

### 00:10–00:20｜三家公司与关系结构

**页面操作**

- 鼠标依次轻扫中国船舶、中国重工、中国动力。
- 停在其中一个公司节点约 2 秒，显示关联事件和连接线高亮。

**旁白/字幕**

> 上方是中国船舶、中国重工和中国动力。下方事件由证据版本托举，形成“证据、事件、公司”的可追溯关系。

### 00:20–00:30｜2024-09-03 筹划停牌

**页面操作**

- 点击 `2024-09-03 · 筹划停牌`。
- 聚焦中国船舶，再聚焦中国重工。
- 让灰色公司泡泡、最后交易日和最后收盘价保持可见。

**旁白/字幕**

> 回到二〇二四年九月三日，中国船舶和中国重工处于停牌状态。灰色只表示当时不能交易，不等于利空；页面显示的是停牌前最后交易日和最后收盘价，不是伪实时行情。

### 00:30–00:45｜2024-09-19 预案复牌

**页面操作**

- 点击 `2024-09-19 · 预案复牌`。
- 依次聚焦三家公司，让三种市场观察保持可读。
- 不遮挡“观察到 +3.32%”“观察到 -2.41%”“观察到 -5.40%”等页面已有文字。

**旁白/字幕**

> 预案披露后，两家合并主体复牌，中国动力也出现同期市场变化。页面只说“观察到的变化”：中国船舶、中国重工和中国动力表现不同，但这些价格变化不能证明是事件造成的，更不能用来证明传闻真假。

### 00:45–00:55｜2025-09-16 实施完成

**页面操作**

- 点击 `2025-09-16 · 实施完成`。
- 画面停留在完整四事件和十五个关键版本节点。

**旁白/字幕**

> 到二〇二五年九月十六日，换股吸收合并已经实施完成。中国重工明确显示为终止上市，中国动力的相关股份承继关系也已经完成。

### 00:55–01:05｜逐公司影响与双状态

**页面操作**

- 聚焦主合并事件。
- 让连接到三家公司的关系线同时高亮。
- 随后短暂聚焦中国动力权益承继辅助事件。

**旁白/字幕**

> 同一事件对不同公司不必只有一个颜色。系统分别保留利多、利空、混合和暂不明确判断。事件已确认、执行已完成和市场已经计价，也是三个不同概念。

### 01:05–01:17｜打开分析过程：来源与去重

**页面操作**

- 点击“查看分析过程”。
- 展示面板顶部和步骤 1、2。

**旁白/字幕**

> 这次演示使用十八份已经保存的来源快照，不是实时抓取。程序先按文档编号、规范化链接、内容哈希和标题时间做精确去重，再折叠转载和镜像，同时保留每条来源记录的追溯路径。

### 01:17–01:28｜事件聚类、AI请求和保存结果

**页面操作**

- 在分析面板中向下滚动，依次显示步骤 3、4、5。
- 保证“四个事件”“material-analysis-v1”“model unknown”可读。

**旁白/字幕**

> 结构化字段和文本关系最终形成四个事件簇。Prompt Builder 生成严格请求和 JSON Schema；本次由 SavedAnalysisProvider 读取保存的分析结果，模型名称无法确认，所以记录为 unknown，没有调用在线模型。

### 01:28–01:38｜校验与视觉应用

**页面操作**

- 继续滚动到步骤 6、7。
- 显示“结构与引用校验”和“应用到事件浮力图”。

**旁白/字幕**

> 结果在进入页面前必须通过结构、引用、枚举、时间和语义校验。不存在的来源、非法状态、AI生成的价格，以及把观点冒充事实，都会被拒绝。只有校验通过的 visual-result 才能驱动泡泡图。

### 01:38–01:48｜返回主图并展示关联高亮

**页面操作**

- 关闭分析面板。
- 键盘 Tab 聚焦中国重工公司节点，再聚焦主事件和一个版本节点。
- 每个焦点保持约 2 秒，让浮层和关系链清楚显示。

**旁白/字幕**

> 页面支持鼠标和键盘聚焦。红色表示利多，绿色表示利空，红绿双色表示混合，银白表示暂不明确。关键判断可以沿 event_id、claim_id 和 source_id 回到实际材料。

### 01:48–01:58｜边界与免责声明

**页面操作**

- 镜头回到完整最终快照。
- 保证底部“不构成投资建议”和图例可见。
- 最后 1 秒淡出，不要黑屏超过 0.5 秒。

**旁白/字幕**

> 当前版本没有实时抓取、外部采集 Agent 或在线模型调用。行情变化只表示时间相关观察，不证明因果。所有分析仅用于产品演示，不构成投资建议。

预计总时长：约 118 秒。录制时可把开场、节点切换或滚动各缩短 1–2 秒，将最终时长控制在 105–118 秒。

## 录制与成片命令建议

推荐使用系统录屏或 OBS 只捕获浏览器内容区域，设置：

- 画布与输出：1440×900；
- 帧率：30 fps；
- 编码：H.264；
- 容器：MP4；
- 视频码率：4–8 Mbps；
- 音频：AAC 128–192 kbps；无旁白时可不保留音轨。

成片保存为：

```text
outputs/event-intelligence-web/event-intelligence-demo.mp4
```

如果录制为其他格式，可在安装 FFmpeg 的环境中转码：

```powershell
ffmpeg -i input-recording.webm -c:v libx264 -pix_fmt yuv420p -r 30 -movflags +faststart -c:a aac -b:a 160k outputs/event-intelligence-web/event-intelligence-demo.mp4
```

验证成片：

```powershell
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height,r_frame_rate -of default=noprint_wrappers=1 outputs/event-intelligence-web/event-intelligence-demo.mp4
```
